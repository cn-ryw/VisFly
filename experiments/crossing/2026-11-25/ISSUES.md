# 三机安全起点与机间终止实验记录

实验于 2026 年 11 月 25 日启动。时间、权重和统计以落盘日志为准。

| 发现 | 实测与处理 |
|---|---|
| 旧环境允许开局时机体已重叠 | 旧留出有 5/100 队在初始帧接触。开发集种子 1037、1072、1097 的原始最近中心距分别为 18.80、4.70、13.72 cm。改为按原生成器重新抽取不合法的整队提案。已合法的 97 个开发起点逐坐标保持一致。三处新开局为 86.06、34.07、111.25 cm。两组 100 个修正开局相同，最小 21.50 cm。证据见 smoke/legal-start-dev-probe.log。 |
| 斜向相切的浮点边界 | 静止机对的位移为 (0.12, 0.16, 0) m，欧氏距离正好是 0.20 m。最初直接比较平方，0.04 与 0.20² 的舍入差会误触发终止。已将初次处理组在 147,456 交互处停止并隔离至 smoke/peer-pre-tangent-training。正式处理组从零重启，并按米比较，采用独立几何验收已有的 10⁻¹² m 相切数值容差。对照组不执行该终止分支。 |
| 原版训练自动复位会覆盖终末深度 | 原版 Gym 将终止深度保存为缓冲区视图，自动复位时可能覆盖这部分深度。两组保留相同的 PPO 超时自举行为。评估使用单回合 test 模式，在明确终止后保存真实末帧。证据见 smoke/auto-reset-terminal-depth.txt。 |
| 数据口径 | 对照组训练中的新增机间终止次数定义为 0，只表明该条件关闭。所有冻结权重在同一套安全起点、机间终止、独立轨迹审计下比较。第一接触子步给出 2.5 ms 区间，同一区间并列的在线机对以 12、13、23 顺序记录，终止步最近中心距取该 20 ms 周期全部机对的最小值。 |
| 两份零步 ZIP 的整包哈希不同 | 解包逐项核验，73 个策略张量、空 Adam 状态和四类首帧观测完全相同，初始 24 个团队也一致。两组共用一次零步确定性评估。证据见 setup/initialization-parity.json。 |
| 相切修正前后有两份旧权重复测 | 在相同的 100 个开发起点逐份比较，动作、三路深度、轨迹、结局以及全部 NPZ 的 SHA-256 均相同。正式统计取修正后版本。相同的 230,229,752 字节轨迹文件已使用硬链接存一份；两次运行的元数据分别保留。证据见 smoke/reference-tangent-comparison.json。 |
| 101 万交互时机间接触减少、碰地回合增加 | 开发集 100 队，机间首碰由 13 队降到 6 队，地面首碰由 22 队增到 60 队。种子 1000 的相同起点，对照组在第 66 步完成，3 号机当时高 2.02 m。机间终止组在第 67 步第 3 子步，3 号机的中心高仅 9.94 cm，10 cm 半径机体已触地，纵向位置 x = 7.98 m。两个回合时长不同，按物理时间对齐到最短公共前缀。此例说明该次失败的物理原因；训练为何偏向该轨迹需另行验证。证据见 evaluation/development/early-ground-case.json。 |
| 切换 Windows 导致运行中状态丢失 | 22:47 冻结训练和评估，复制最近一次更新后的滚动权重和日志。两份 ZIP 已重新加载，每组 73 个策略张量和 33 个参数的 Adam 状态均已验证。下次分别接第 150、125 轮。重新开始的 24 个场景单列为关机中断，旧日志多出的 202,752、442,368 条采样只保留作记录。下次成绩标明分段续训及两个恢复时点。 |
| 临时性能模式的加速未获证实 | 两组都在同一台机器并行运行。接电性能模式和 CPU 核心分配的小样本测量分别为每秒 1,129 与 1,105 次交互，改动前为 1,126 与 1,125。关机暂停后已恢复平衡模式、撤销临时 CPU 亲和性并复核。 |
